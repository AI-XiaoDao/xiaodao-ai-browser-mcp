# 🚀 小白使用指南（零基础 3 分钟上手）

> 不用懂编程。你只需要会**双击**、**复制粘贴**和**说话**。

---

## 先搞清楚一件事

**它不是一个"双击就能用"的软件。** 它是一个 **MCP 服务器** —— 由 AI 客户端（Cursor 等）自动拉起来干活，
不监听端口。**浏览器窗口默认是隐藏的、不占桌面**（v3.3.2 起）：它在后台真实跑着一个 Chromium（CEF）浏览器，
需要看的时候让 AI 调用 `browser_show_window {visible:true}` 就能显示出来。

> 🪟 **找不到窗口是正常的**，不是坏了。默认隐藏是为了不打扰你干活。
> 想让它一直显示：命令行加 `--visible`（或 `--show-window`），或在 `mcp_config.json` 里写 `"start_hidden": false`。
> 顺手关掉那个窗口也不用担心——默认只**隐藏窗口**，服务继续跑（要"点 X 就整个退出"则写 `"exit_on_window_close": true`）。

**本版免费发布：解压即用，没有卡密、没有机器码、没有任何激活步骤。**

两步走：**解压 → 配置 Cursor**。

## 第一步：解压（30 秒）

1. 解压下载的压缩包。**别只把 exe 单独拷出来** —— 同目录的 `.dll` / `.pak` / `locales/` 是浏览器内核，缺了起不来
2. （可选）双击 **AI-Fbowser-Mcp.exe**：窗口会打印版权信息与**按你电脑路径生成好的客户端配置**，复制走即可，看完按任意键关掉

## 第二步：让 Cursor 认识它（1 分钟）

**路径不用你手填。** 直接运行下面任意一种，它会把**你这台机器上 exe 的真实完整路径**填好，输出一段可直接粘贴的 JSON：

- **双击 `AI-Fbowser-Mcp.exe`**（最简单，打印完停在「按任意键退出…」）
- 或在 cmd / PowerShell 里运行（等义开关 `--dump-config`）：

```
AI-Fbowser-Mcp.exe --print-config
```

> 💡 `--print-config` 只是**打印配置就退出** —— 不启动 MCP 服务、不建浏览器、不占桌面。
> 想直接存成文件：`AI-Fbowser-Mcp.exe --print-config > mcp.json`

把打印出来的整段 JSON 复制到 Cursor：**Cursor 设置 → MCP → 添加服务器**。内容形如（下面只是样子，**别照抄 `D:/你的解压路径` 这种占位符**）：

```json
{
  "mcpServers": {
    "ai-browser": {
      "command": "<exe 的真实完整路径，由 --print-config 自动填好>",
      "args": ["--mcp-stdio"]
    }
  }
}
```

保存后**完全重启 Cursor**。看到 `browser_navigate`、`browser_snapshot` 等工具就是成功了。

> ✅ 就这三行 —— **不需要端口、不需要桥接脚本、不需要任何环境变量。**

## 第三步：用大白话指挥浏览器

在 Cursor 对话框直接说（**不要写代码**）：

| 你想干什么 | 就这么说 |
|-----------|---------|
| 打开网页 | 「打开百度首页」 |
| 看页面上有什么 | 「告诉我这个页面上有哪些按钮和输入框」 |
| 按文字点按钮 | 「点击『登录』按钮」 |
| 填表 | 「用户名填 test，密码填 123456」 |
| 采集数据 | 「把商品列表的标题和价格整理成表格」 |
| 截图 | 「截个图给我看看」 |
| 等页面加载完 | 「等页面加载完再操作」 |
| 看最近发生了啥 | 「最近浏览器里发生了什么事件」 |

AI 会自动组合 `browser_navigate` / `browser_snapshot` / `browser_click_text` / `browser_fill_form` / `browser_screenshot` / `browser_event` 等 **348 个工具**完成任务。

> 💡 不确定有哪些工具可用时，直接问 AI：「用 mcp_help 搜一下『截图』相关的工具」。

## 常见问题

**Q: 双击没反应，或者窗口一闪而过？**
A: **一闪而过不是正常现象**。它不是普通软件，所以平时确实不需要你双击 —— 但正常双击会打印版权信息与客户端配置 JSON，然后停在「按任意键退出…」等你按键。**一闪就没**通常是同目录缺 `*.dll` / `*.pak` / `locales\`，或被安全软件拦了，请对照解压包补齐文件。配置好 Cursor 之后，是 **Cursor 自己拉起它**，你不需要手动开。

**Q: Cursor 里看不到工具？**
A: 配置后必须**完全重启 Cursor**（不是重开对话）。

**Q: 需要卡密 / 提示激活吗？**
A: **不需要。** 本版免费发布，程序内没有任何激活前置条件，也没有卡密、机器码或 `license.json`。

**Q: 怎么彻底退出？**
A: 在 Cursor 里说「关闭AI浏览器」（它会调用 `browser_shutdown`），或者直接退出 Cursor。

**Q: 会连网泄露数据吗？**
A: 程序**不监听任何端口**，MCP 通信只走 Cursor 与它之间的本机管道，不存在对外的服务端口。**但它本身就是一个真实浏览器**：你让它访问哪个网站，它就会像普通浏览器一样与那个网站通信（这是它干活的前提），所以别把它当成"绝不上网"的沙箱。
