# 已知边界 / Known limits

> 与 [ROADMAP.md](ROADMAP.md) 配套：本文件写"**现在**是什么样"，路线图写"**怎么修、如何验收**"。已缓解/已修的条目不留旧结论。

1. **未做代码签名** —— 发布包 exe 未签名，SmartScreen 会提示"未知发布者"，企业环境可能拦截。
   处置：见 [CODE-SIGNING.md](CODE-SIGNING.md)（需证书持有方执行；仓库侧流程与 CI 接入位已备好）。
2. **缓存库"内容型"毒化** —— **触发条件无法从外部构造**，当前判据是启发式（启动真实往返自检 + 失败即隔离换新 + 隔离产物保留最近 3 套）；
   根因未定位。3.3.4 计划改为 `PRAGMA integrity_check` 确定性判据（见路线图）。
3. **全忙期排队** —— 非 `tools/call` 的 `initialize` / `workflow_stop` 在工作池饱和时仍入队（**有界延迟，不丢请求**）；
   `ping` 与 `tools/list` 已由读线程快答。3.3.4 计划再吸收无 id 通知并给 `initialize` 加快照（见路线图）。
4. **日志编码** —— 默认 936/GBK（与中文 Windows 控制台一致）；因 CEF 子进程自身输出 UTF-8，默认模式下为**混合编码**。
   置 `AI_BROWSER_MCP_STDERR_UTF8=1` 可整条流切 UTF-8（实测替换符 0）；默认值不变以保证兼容。
5. **exe 不逐字节可复现** —— 链接时间戳不同 ⇒ 同源码两次编译 MD5 不同（文件大小一致）。
   因此**以 Release 内层 exe 的 MD5 为准**，不要用跨批次 MD5 判断版本。
6. **第三方依赖** —— 运行需 FBrowser/CEF 运行库（已随成品包提供，x64/x86 各一套）；构建需火山视窗编译器与 FBrowser 火山模块。
7. **GUI 客户端与长浸泡未验证** —— 协议级客户端矩阵 7/7 已实测；真实 GUI 客户端与 1–2 小时浸泡仍待补（见路线图）。
