# AI浏览器 MCP 文档目录

编译后随 exe 一并复制到**解压目录的 `docs\` 子目录**（`linker` 是源码工程的编译输出目录名），直接在本机打开这些文件即可阅读。
（程序**不监听任何端口**，故没有可访问的在线文档地址。）

| 文件 | 读者 | 说明 |
|------|------|------|
| **[客户使用手册.md](./客户使用手册.md)** | **终端客户** | 安装（免费版无需激活）、接入 Cursor、自然语言示例、FAQ |
| [快速使用指南.md](./快速使用指南.md) | 新用户 | 零基础 3 步上手（解压 → 看配置 → 接入 Cursor） |

## 工具清单的权威来源

以运行时的 **MCP `tools/list`** 为准（由 AI 客户端自动拉取）。
工具很多，**不建议通读** —— 用 `mcp_help {query:"关键词"}` 按需搜索，再用 `mcp_help {tool:"名字"}` 取单个工具的完整说明。
