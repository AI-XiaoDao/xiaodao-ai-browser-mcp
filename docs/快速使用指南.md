# 快速使用指南

> 零基础 3 步。更详细的说明（含常见问题）见 **小白使用指南.md**。

---

## 它是什么

一个 **MCP 服务器**（351 个浏览器工具），由 AI 客户端（Cursor 等）自动拉起。
**不是双击就能用的软件** —— 双击只用来查看版权信息与客户端配置。
**浏览器窗口默认隐藏、不占桌面**（v3.3.2 起）：找不到窗口是正常的，想看就加 `--visible` 启动，或让 AI 调 `browser_show_window {visible:true}`。

**本版免费发布：解压即用，没有卡密、没有机器码、没有任何激活步骤。**

## 三步上手

### 1️⃣ 解压

解压下载的压缩包。**别只把 exe 单独拷出来** —— 同目录的 `.dll` / `.pak` / `locales/` 是浏览器内核，缺了起不来。

### 2️⃣ 看一眼版权与配置（可选）

双击 **AI-Fbowser-Mcp.exe** → 窗口打印版权信息 + **按你电脑路径生成好的客户端配置 JSON**，复制走即可。

### 3️⃣ 配置 Cursor

**路径由程序自动填好，不用你手写。** 用第 2 步双击打印出来的那段 JSON —— 或者在 cmd / PowerShell 里跑
`AI-Fbowser-Mcp.exe --print-config`（只打印、不启动服务、不占桌面），复制它的输出。

Cursor 设置 → MCP → 添加服务器，粘进去的内容形如：

```json
{
  "mcpServers": {
    "ai-browser": {
      "command": "<exe 真实完整路径，自动填好 —— 别照抄占位符>",
      "args": ["--mcp-stdio"]
    }
  }
}
```

**完全重启 Cursor**。出现 `browser_navigate`、`browser_snapshot` 等工具即成功。

> ✅ 就这三行 —— **不需要端口、不需要桥接脚本、不需要环境变量。**

## 怎么说

在 Cursor 里直接说人话（不要写代码）：

| 想干什么 | 就这么说 |
|---------|---------|
| 打开网页 | 「打开百度首页」 |
| 看页面有什么 | 「告诉我这个页面上有哪些按钮和输入框」 |
| 按文字点按钮 | 「点击『登录』按钮」 |
| 填表 | 「用户名填 test，密码填 123456」 |
| 采集数据 | 「把商品列表的标题和价格整理成表格」 |
| 截图 | 「截个图给我看看」 |
| 等加载完 | 「等页面加载完再操作」 |

不确定有哪些工具时，直接让 AI 搜：「用 `mcp_help` 搜一下『截图』相关的工具」。

## 常见问题

**Q: 双击没反应 / 窗口一闪而过？**
A: **一闪而过不是正常现象**。正常双击会打印版权信息与客户端配置 JSON，并停在「按任意键退出…」等按键；一闪就没多半是同目录缺 `*.dll` / `*.pak` / `locales\`。平时不需要你双击 —— 配置好后由 Cursor 自动拉起。

**Q: Cursor 里看不到工具？**
A: 必须**完全重启 Cursor**（不是重开对话）；确认配置里 `command` 指向 exe、`args` 为 `["--mcp-stdio"]`。

**Q: 需要卡密 / 提示激活吗？**
A: **不需要。** 本版免费发布，程序内没有任何激活前置条件。

**Q: 电脑上怎么找不到浏览器窗口？**
A: **正常**，本版**默认隐藏窗口、不占桌面**。要一直显示：启动参数加 `--visible`，或配置里写 `"start_hidden": false`；只是临时看一眼就让 AI 调 `browser_show_window {visible:true}`。手动关掉窗口（X）默认只**隐藏**，服务照常跑。

**Q: 怎么彻底退出？**
A: 在 Cursor 里说「关闭AI浏览器」（调用 `browser_shutdown`），或退出 Cursor。

**Q: 会连网泄露数据吗？**
A: 程序**不监听任何端口**，MCP 通信只走 Cursor 与它之间的本机管道。**但它本身是真实浏览器**：你让它访问哪个网站，它就会与那个网站正常通信（这才能采集/填表），不是"绝不上网"的沙箱。
