## 一、产品是什么？

**AI浏览器** 是一款 **MCP 服务器**：它内嵌一个真实的 **Google Chromium（CEF）** 浏览器，把浏览器能力封装成 **351 个标准 MCP 工具**，交给 AI 来开。

您在 Cursor 里用自然语言描述任务，AI 就会调用这些工具去操作浏览器：

- 打开指定网页
- 自动填表、点击按钮
- 读取页面文字与元素
- 查看网络请求记录
- 截图、改指纹、断点调试、拦截修改接口等

> ⚠️ **它不是"双击就能用"的软件。** 它由 AI 客户端（Cursor 等）**自动拉起**，平时不占窗口、**不监听任何端口**。
> 本版为**免费发布，无需卡密激活**；双击 exe 会打印版权信息与**按本机路径生成好的客户端配置**，复制即用。

## 五、三种使用方式

### 方式 A：在 Cursor 里用自然语言（推荐）

适合：不懂编程的客户、日常「帮我打开某网站并操作」。

配置好之后（见第六节），在对话里直接说：

| 您可以说 | AI 会做什么 |
|----------|-------------|
| 「打开百度」 | `browser_navigate` 打开 https://www.baidu.com |
| 「当前页面标题是什么」 | `browser_get_title` |
| 「在搜索框输入天气并点击搜索」 | `fill_set_value` + `fill_click` |
| 「列出最近的网络请求」 | `browser_network` list |
| 「刷新页面」 | `browser_reload` |
| 「滚动商品列表，采标题价格 JSON」 | `evaluate` 滚动 + `dom_query` / `collect` |
| 「扫描 POST，标出疑似加密字段」 | `browser_inject` Hook + 网络对比 |
| 「提交时下断点，定位 sign 函数给源码」 | `debugger_*` |
| 「把这套流程存成 workflow 并跑一遍」 | `workflow_*` |

> 💡 **不知道有哪些工具可用时，直接问 AI**：「用 `mcp_help` 搜一下『截图』相关的工具」。
> 工具共 351 个，**不建议通读** —— 按需搜索更省时间。

### 方式 B：其他 MCP 客户端

Claude Desktop、Cline、Windsurf 等任何支持 MCP 的客户端，配置方式与 Cursor 相同：
**命令填 exe 路径、参数填 `--mcp-stdio`**（见第六节，把 `command`/`args` 照抄即可）。

### 方式 C：自有程序直连

适合：集成到公司内部系统。

- 传输：**标准 MCP over stdio**（JSON-RPC 2.0，逐行分隔），程序由您的代码 `spawn` 拉起
- 启动参数：`--mcp-stdio`
- 授权：**无**。本版免费发布，拉起即可用，不需要传任何卡密或环境变量
- 注意：**不是 HTTP，也没有可连的端口**

## 六、Cursor 接入（分步说明）

### 第 1 步：打开 MCP 设置

Cursor → 设置 → MCP → 添加服务器（或直接编辑 `.cursor/mcp.json`）。

### 第 2 步：填入配置

**不用手填路径** —— 直接把**第 2 步双击时打印出来的那段 JSON** 整段复制过来即可（它已经按您本机的真实路径生成好了）。
不想双击的话，在 cmd / PowerShell 里跑 `AI-Fbowser-Mcp.exe --print-config`，输出的就是同一段内容（**只打印、不启动服务、不占桌面**）。

内容形如：

```json
{
  "mcpServers": {
    "ai-browser": {
      "command": "<您的 exe 真实完整路径，由双击 / --print-config 自动填好>",
      "args": ["--mcp-stdio"]
    }
  }
}
```

> ⚠️ 尖括号里是**说明文字**，不是可用路径。请用打印出来的那一份，**不要手写** `D:/您的解压路径` 之类的占位符。
> 若确实要手填：路径含空格或中文时用正斜杠 `/` 或双反斜杠 `\\`。

> ✅ **就这三行。** 不需要 `node`、不需要 `mcp_bridge.js`、不需要任何环境变量。

### 第 3 步：完全重启 Cursor

不是"重开对话"，是**彻底退出 Cursor 再打开**。之后在 MCP 工具列表里就能看到 `ai-browser` 的 351 个工具。

### 第 4 步：试一句

在对话输入：**「用浏览器打开 https://www.example.com 并告诉我标题」**。

## 七、常见业务场景

### 7.1 日常打开网页

对 AI 说：「打开目标网站」或「导航到 https://example.com」。

### 7.2 自动填表登录

对 AI 说：「在 `#username` 填入 xxx，在 `#password` 填入 yyy，点击登录按钮」。
（需页面有稳定的选择器；复杂站点可让 AI 先 `browser_dom_query` 分析结构。）

### 7.3 查看接口 / 网络活动

对 AI 说：「开启网络日志并列出最近 50 条请求」。

注意：默认**看不到 POST 请求体**。需要详细记录时对 AI 说：

```
browser_network detail_enable   # 开启详细记录(含 POST body)
browser_network list            # 列出网络日志
```

### 7.4 批量重复操作（工作流）

对 AI 说：「执行工作流 hello」→ 对应 `workflow_run`。
预置工作流在 `workflows/` 目录，可按需定制 JSON 步骤链。

### 7.5 数据采集（一句话）

对 AI 说：**「滚动加载商品列表，把标题、价格、链接采成 JSON」**。

AI 通常会：打开页面 → 滚动或点「加载更多」→ 读 DOM → 整理成表格或 JSON 返回。
若数据为空：说明是否要**先登录**、**多滚几屏**，或让 AI 先试探选择器。

### 7.6 逆向算法（找加密字段）

对 AI 说：**「扫描 XHR/fetch 的 POST，标出疑似加密的字段」**。

注意：普通网络列表**看不到 POST 正文**，AI 会用 **Hook 注入**（`browser_inject`）或资源拦截来抓 body；
也可先开 `browser_network detail_enable`。

**逆向 vs 定位**：逆向是找「哪个字段/请求被加密」；定位是找「加密逻辑在哪个 JS 函数」（见 7.7）。

### 7.7 定位算法（找 sign 函数）

对 AI 说：**「提交时下断点，跟到计算 sign 的函数，把源码片段给我」**。

AI 会设断点、读调用栈与源码。
断点不命中时：改在 `fetch` 发送处断住，或让 AI 搜索 `sign` / `md5` 相关脚本。

### 7.8 页面卡住 / 调试后无响应

对 AI 说：「恢复页面并停止加载」。对应工具：`browser_debugger_resume`、`browser_stop`、
必要时 `browser_restore_gui`、`browser_reload`。

## 八、修改配置

`mcp_config.json` 里可调整的浏览器行为（改完需让 AI 调用 `browser_shutdown` 后重连）：

| 字段 | 作用 |
|------|------|
| `enable_network_log` | 是否记录网络日志（默认 `true`） |
| `enable_console_log` | 是否记录控制台日志（默认 `false`） |
| `auto_download_save` | 自动保存下载文件（默认 `true`） |
| `auto_dismiss_js_dialog` | 自动关闭 JS 弹窗（默认 `false`） |
| `window_topmost` | 浏览器窗口置顶（默认 `true`） |
| `start_hidden` | **窗口是否隐藏（默认 `true`）**。默认 `true` = 窗口创建后立即隐藏、不占桌面；写 `false` 才让窗口常显 |
| `exit_on_window_close` | **点窗口 X 的语义（默认 `false`）**。默认 `false` = 只隐藏窗口、服务继续跑；写 `true` 才随 X 整体退出 |
| `enable_media_stream` / `enable_autoplay` | 媒体播放相关 |
| `disable_proxy` | 禁用代理 |

> ⚠️ 文件里的 `port` / `bind_address` / `api_key` / `disable_auth` 是**历史遗留字段**，
> 现行版本**不监听端口、认证闸门已停用**，这些值不生效，删掉也可以。
>
> ❗ **但 `rate_limit_per_minute` 不在这批里 —— 它至今仍然生效**：`0`（默认）= 不限速；
> `>0` 时按每分钟上限限流，超限请求会被拒（错误码 `-32000`「请求过于频繁」，附 `Retry-After` 秒数）。

二次开发者的编译说明在**源码工程根目录**的 `编译说明.txt`（该文件**不随发布包提供**，发布包里只有 exe 与 `docs\`）。

## 九、常见问题（客户版）

| 问题 | 解决办法 |
|------|----------|
| 双击没反应 / 窗口一闪而过 | 平时不需要双击（由 Cursor 自动拉起）；但**一闪而过不是正常现象** —— 正常双击会打印版权信息与客户端配置 JSON 并停在「按任意键退出…」。一闪就没请检查同目录 `*.dll` / `*.pak` / `locales\` 是否齐全 |
| Cursor 里看不到工具 | 必须**完全重启 Cursor**（不是重开对话）；确认配置里 `command` 指向 exe、`args` 为 `["--mcp-stdio"]` |
| 需要卡密 / 提示激活吗？ | **不需要**。本版免费发布，程序内没有任何激活前置条件 |
| 桌面/任务栏里找不到浏览器窗口 | **正常**：本版**默认隐藏窗口**（`start_hidden` 默认 `true`），服务在后台照常干活。想看就加 `--visible` 启动，或在 `mcp_config.json` 写 `"start_hidden": false`，也可以运行期让 AI 调用 `browser_show_window {visible:true}` |
| 手动关掉窗口会怎样？ | **默认只是隐藏窗口**（`exit_on_window_close` 默认 `false`），桌面立刻干净而 MCP 继续可用，AI 的工具不会断。想让它「点 X = 整个退出」，把 `exit_on_window_close` 写成 `true` |
| 关了窗口还能用吗？ | 您不需要手动开它 —— 由 Cursor 拉起、随 Cursor 退出；窗口关掉（隐藏）也不影响使用 |
| 怎么完全退出？ | 在 Cursor 里说「关闭AI浏览器」（调用 `browser_shutdown`），或退出 Cursor |
| AI 说找不到浏览器 | 等几秒再试；或让 AI 调用 `browser_create` 主动建一个 |
| 网络列表是空的 | 需先打开网页产生请求；确认 `enable_network_log` 为 true |
| 扫描脚本报 timeout | 让 AI 调用 `browser_debugger_resume` + `browser_stop` 恢复页面 |
| 采集结果是空的 | 是否要先登录；说「滚动 N 屏后再采」；让 AI 先 `dom_query` 试探 |
| 接口加密参数怎么看？ | 见 7.6；对 AI 说「扫描 POST 加密字段」 |
| 文档打不开 | 直接打开安装目录 `docs\` 下的文件（程序不提供网页，因为不开端口） |
